## 🚀 How to Host on GitHub Pages

1. Open [GitHub](https://github.com/) and create a repository (e.g., `for-aklu-infinite` or update your existing repo).
2. Upload the files from the `03-Nov` folder:
   - `index.html`
   - `style.css`
   - `script.js`
3. Go to **Settings** > **Pages**.
4. Under **Build and deployment > Branch**, select `main` (or `master`) and folder `/ (root)`, then click **Save**.
5. GitHub will provide your live link (e.g. `https://<your-username>.github.io/<repo-name>/`).
